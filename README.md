# PRESIDENT — شبیه‌ساز ریاست‌جمهوری

بازی مدیریتی و استراتژیک تک‌نفره، کاملاً فارسی و راست‌چین، ساخته‌شده با HTML/CSS/JavaScript خالص (بدون وابستگی). روی موبایل اندروید و مرورگر دسکتاپ اجرا می‌شود.

## اجرا
- **ساده‌ترین راه:** فایل `dist/index.html` را در مرورگر باز کنید (حتی از حافظه گوشی). اطلاعات بازی در IndexedDB مرورگر ذخیره می‌شود.
- **با سرور محلی:** `npm run serve` و سپس `http://localhost:8080`
- **نصب روی اندروید (PWA):** پوشه `dist/` را روی هر میزبان HTTPS (مثلاً GitHub Pages یا Netlify) قرار دهید، با Chrome باز کنید و «افزودن به صفحه اصلی / Install app» را بزنید. پس از اولین بار آفلاین هم کار می‌کند.
- **ساخت APK (اختیاری، در این بسته ساخته نشده):** با Capacitor: `npm i @capacitor/core @capacitor/cli @capacitor/android` ← `npx cap init PRESIDENT com.example.president --web-dir=dist` ← `npx cap add android` ← `npx cap open android`.

فونت وزیرمتن از Google Fonts بارگذاری می‌شود؛ بدون اینترنت از فونت فارسی سیستم استفاده می‌شود.

## ساختار
| فایل | کار |
|---|---|
| `src/data.js` | کشورها، وزارتخانه‌ها، پروژه‌ها، فناوری‌ها، آرکی‌تایپ‌های کشور خیالی |
| `src/engine.js` | موتور اقتصادی، نوبت ماهانه، رویدادها، هوش مصنوعی، دیپلماسی، کنش‌های بازیکن |
| `src/db.js` | ذخیره‌سازی IndexedDB (جدول‌های games / worlds / countries / pacts) |
| `src/map.js` | نقشه نقطه‌چین جهان و پرچم کشور خیالی |
| `src/app.js`, `src/style.css` | رابط کاربری |
| `build.js` | ساخت `dist/` (یک فایل HTML تک‌پارچه + فایل‌های PWA) |
| `test/` | تست موتور، تست مرورگری، تست اجرا از file:// |

پس از تغییر در `src/` دستور `node build.js` را اجرا کنید. `npm test` همه آزمون‌ها را اجرا می‌کند.

## موتور اقتصادی (خلاصه)
- هر ماه: درآمد (مالیات، انرژی، پروژه‌ها، تعرفه) و هزینه (بودجه بخش‌ها، بهره بدهی، نگهداری) محاسبه و به خزانه اعمال می‌شود؛ کسری خزانه به استقراض اضطراری تبدیل می‌شود.
- رشد ← زیرساخت، آموزش، سلامت، مصرف، تجارت، انرژی، نرخ بهره، فناوری، وزیران، رقابت و رویدادها.
- تورم ← کسری بودجه، رشد، ارزش پول، قیمت انرژی، نرخ بهره، چاپ پول در بدهی بسیار سنگین.
- بیکاری ← رشد، آموزش، اشتغال پروژه‌ها، وزیر کشور، فناوری هوش مصنوعی.
- رضایت مردم ← بیکاری، تورم، سطح خدمات، مالیات، رفاه، کمبود انرژی، بدهی، رویدادها.
- پایان بازی: برکناری (رضایت زیر ۱۵٪ سه ماه)، ورشکستگی (بدهی بیش از ۳۵۰٪ GDP) یا باخت در انتخابات هر ۴۸ ماه.

## محدودیت‌های فعلی (صادقانه)
- **حالت چندنفره پیاده‌سازی نشده است.** فقط ساختار داده (فیلد `owner`، لیست `players`، جدول‌های جدا) برای توسعه آینده آماده است؛ دکمه آن در منو غیرفعال است.
- اعداد کشورها تقریبی و برای تعادل بازی کالیبره شده‌اند، نه داده رسمی.
- نقشه جهان یک نقشه نقطه‌چین ساده است، نه نقشه دقیق جغرافیایی.
- ارزش پول هر کشور از ۱۰۰ شروع می‌شود (شاخص نسبی، نه نرخ برابری واقعی).
- فایل APK ساخته نشده؛ مسیر ساخت بالا ذکر شده است.
